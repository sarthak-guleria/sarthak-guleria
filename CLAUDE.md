# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Static personal site (resume + writing) hosted on GitHub Pages at `sarthak-guleria.github.io/sarthak-guleria/`. No build step, no framework, no package manager. Open HTML files directly in a browser or serve with any static server (e.g. `python3 -m http.server 8080`).

## Structure

- `index.html` — homepage (resume/portfolio)
- `writing.html` — article index listing
- `writing/` — individual article HTML files
- `writing/images/` — article images (screenshots, charts, diagrams)
- `og-images/` — og:image source templates (see OG Images section below)

## Design System

All pages share the same CSS variables (defined inline per file — no shared stylesheet):

```
--bg: #faf8f5          warm off-white body
--bg-subtle: #f5f2ed   section backgrounds, callouts
--ink: #1a1a1a         headings, emphasis
--ink-light: #4a4a4a   body text
--ink-faded: #888      meta, labels, captions
--accent: #2c5530      dark green — tags, step numbers, arrows
--accent-light: #e8f0e8 green tint — tag backgrounds
--border: #e5e2dd      all dividers and outlines
```

Fonts: `Source Serif 4` (body copy), `Inter` (UI/labels/meta), `Caveat` (decorative, homepage only).

## Article Template Pattern

Every article in `writing/` follows the same HTML structure:

1. `<header class="article-header">` — tag, date, read time, title, subtitle
2. Opening `<div class="callout">` — one-paragraph frame: personal observation or hook, then scope
3. `<h2>` sections with body paragraphs
4. Visual components inline: `.stat-row`, `.steps-list`, `.risk-grid`, `<figure>`, `.il-curve`, `.compare-table`
5. `.tool-cta` → `.end-cta` → `.disclaimer` → `<footer class="article-footer">`

Reuse component CSS from an existing article rather than writing new styles from scratch.

## Writing Style

- Practitioner's voice: direct, technical, no hype. Written as "I figured this out, here's what matters."
- Short sentences. Near-fragments for impact. No em dashes — use colons, commas, or periods instead.
- **Bold** only the single most important phrase per paragraph — not decorative bolding.
- Numbers are exact and stated plainly: "1.559", "−35.85%", "3–5 loops." No vague ranges.
- Assumes crypto-native reader. Explain mechanisms, not primitives (don't explain what Aave is; do explain what E-Mode does).
- No hype language. No "alpha." No "you can make money." Disclaimers go at the bottom, tersely.
- Section titles are declarative noun phrases: "The setup", "The math", "Risk analysis."
- No AI-tell phrases: "Concretely:", "In practice:", "This is the mechanism.", "The honest framing:", "Walk through the example."
- Callout opens with a personal observation ("I've watched..."), not a table of contents for the article.

## Adding a New Article

1. Copy an existing article HTML as the template base.
2. Add an entry to `writing.html` article list (date, tag, title, desc) — newest first.
3. Put images in `writing/images/`.
4. Nav links: `href="../index.html"` (home) and `href="../writing.html"` (back to writing).
5. Generate an og:image — see OG Images section below.
6. Add full OG + Twitter meta tags to the article `<head>` — see SEO section below.

## OG Images

PNGs are auto-generated by `og-images/generate.js` using Puppeteer (headless Chrome). The script renders the site's exact palette and fonts — no manual screenshotting.

**To generate all og:images:**
```bash
cd og-images
npm install       # first time only — installs puppeteer (~170MB, includes Chromium)
npm run generate  # outputs default.png + one PNG per article
```

**To add an og:image for a new article:**
1. Add an entry to the `PAGES` array in `og-images/generate.js`:
   ```js
   { slug: "your-article-slug", title: "Your Article Title" }
   ```
2. Run `npm run generate` — only takes a few seconds
3. The PNG is saved as `og-images/your-article-slug.png`

**Current files:**

- `og-images/aave-loop-guide.png`
- `og-images/hyperliquid-delta-neutral.png`
- `og-images/what-the-heck-is-liquidity.png`

## SEO & Meta Tags

This is a personal site, not a commercial one. Goals: look good when a link is shared, be findable by name, be properly attributed by AI systems.

### What's implemented (as of March 2026)

- `sitemap.xml` — lists all pages with `<lastmod>` dates
- `robots.txt` — points crawlers to the sitemap
- `llms.txt` — tells AI crawlers (ChatGPT, Perplexity, Claude) what content exists and who authored it
- OG + Twitter Card tags on all pages (title, description, type, url, image)
- `og:image` on all pages pointing to generated PNGs in `og-images/`
- `twitter:card: summary_large_image` everywhere
- `<link rel="canonical">` on every page
- `schema.org` Article JSON-LD on each article (headline, author, datePublished)
- `schema.org` Person JSON-LD on homepage (name, url, sameAs for X and LinkedIn)

### Required tags for each new article

```html
<link rel="canonical" href="https://sarthak-guleria.github.io/sarthak-guleria/writing/[slug].html" />
<meta property="og:title" content="[Article title]" />
<meta property="og:description" content="[Meta description]" />
<meta property="og:type" content="article" />
<meta property="og:url" content="https://sarthak-guleria.github.io/sarthak-guleria/writing/[slug].html" />
<meta property="og:image" content="https://sarthak-guleria.github.io/sarthak-guleria/og-images/[slug].png" />
<meta property="article:author" content="Sarthak Guleria" />
<meta property="article:published_time" content="YYYY-MM-DD" />
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:creator" content="@Fren_pm" />
<meta name="twitter:title" content="[Article title]" />
<meta name="twitter:description" content="[Meta description]" />
<meta name="twitter:image" content="https://sarthak-guleria.github.io/sarthak-guleria/og-images/[slug].png" />
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[Article title]",
  "description": "[Meta description]",
  "datePublished": "YYYY-MM-DD",
  "author": { "@type": "Person", "name": "Sarthak Guleria", "url": "https://sarthak-guleria.github.io/sarthak-guleria/" },
  "url": "https://sarthak-guleria.github.io/sarthak-guleria/writing/[slug].html"
}
</script>
```

When adding a new article, update `sitemap.xml` with the new URL and `llms.txt` with the title + one-line description.
